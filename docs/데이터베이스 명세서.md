# 데이터베이스 명세서

이 문서는 ComplianceJB MVP의 PostgreSQL 데이터베이스 구조를 정리합니다.

기준 스키마 파일:

```text
data/init/01-schema.sql
```

## 1. 전체 테이블

| 테이블 | 설명 |
| --- | --- |
| `teams` | 사용자 소속 팀 |
| `users` | 사용자 계정 |
| `review_boards` | 심의 게시물 |
| `review_content_versions` | 버전별 심의 콘텐츠 |
| `review_content_chunks` | 심의 콘텐츠 RAG 검색용 청크 |
| `reference_documents` | 준법 자문 참고 문서 |
| `reference_document_chunks` | 참고 문서 RAG 검색용 청크 |
| `chat_threads` | 심의 콘텐츠 버전별 채팅 thread |
| `chat_messages` | 채팅 메시지 |

## 4. RAG 검색 관련 컬럼

RAG 검색에는 다음 컬럼을 사용합니다.

| 컬럼 | 역할 |
| --- | --- |
| `embedding` | pgvector 기반 semantic search |
| `search_text` | full-text search 원문 |
| `search_vector` | `search_text` 기반 PostgreSQL `TSVECTOR` |
| `metadata` | chunk provenance, page, heading 등 부가 정보 |

`search_vector`는 `search_text`를 기반으로 자동 생성됩니다.

```sql
search_vector TSVECTOR GENERATED ALWAYS AS (
  to_tsvector('simple', coalesce(search_text, ''))
) STORED
```

## 5. MVP에서 미룬 테이블

다음 테이블은 MVP 이후 필요해지면 추가합니다.

| 테이블 | 용도 |
| --- | --- |
| `agent_runs` | Agent 실행 단위 로그 |
| `agent_retrievals` | RAG 검색 결과와 인용 근거 별도 저장 |
| `provider_threads` | OpenAI, Google 등 외부 Agent 플랫폼 thread/session ID 저장 |

MVP에서는 RAG 인용 정보를 `chat_messages.content_json.citations`에 저장합니다.
